# StyleSync 🎮🧍‍♀️👗

A multiplayer VR dress-up experience where you and your friends can style a virtual mannequin together in real-time! Built with Unity, Oculus SDK, Photon for networking, and Ready Player Me for fully customizable avatars.

🌟 Features:
- Full VR support (Oculus Quest 2/3)
- Multiplayer with voice chat (Photon PUN + Photon Voice)
- Dress up a shared Ready Player Me mannequin with interactive clothing
- Real-time AI-powered cloth physics using Unity Sentis
- Dynamic Ready Player Me avatars for each player
- Snap-to-bone clothing system with smooth grab-and-place interaction

🎯 Tech Stack:
- Unity 2023.2+
- Meta XR SDK (Oculus)
- Photon PUN 2 + Photon Voice
- Ready Player Me Unity SDK
- Unity Sentis (ONNX Runtime)
- URP + VR optimization

🚀 Goals:
- Collaborative, creative space for VR fashion fun
- Support for custom avatars and clothing
- Seamless, realistic cloth interaction
- Future: public rooms, saved outfits, and more

🛠️ Status: `In Development`

Made with ☕, 💡, and a lot of VR testing.
